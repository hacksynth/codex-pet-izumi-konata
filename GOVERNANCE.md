# Governance / 治理

`@hacksynth` is the current maintainer and final decision maker for releases, repository
policy, and visual acceptance. Routine decisions are made in issues and pull requests.
Material changes to the pet contract, licensing boundary, or contribution policy require
a documented proposal before implementation.

`@hacksynth` 是当前维护者，对发布、仓库政策和视觉验收拥有最终决定权。常规决策在 Issue 与
Pull Request 中完成。宠物契约、许可边界或贡献政策的重大变更必须先有书面提案。

Maintainers should prefer transparent reasoning, narrow changes, reproducible validation,
and reversible repository settings. Contributor access is granted based on sustained,
constructive participation and may be removed for inactivity or policy violations.

维护者应优先采用透明论证、范围清晰的改动、可复现验证和可逆仓库设置。贡献者权限根据持续、
建设性的参与授予，并可因长期不活跃或违反政策而撤销。
