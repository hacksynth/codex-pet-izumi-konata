# Support / 支持

- Installation questions and showcases: GitHub Discussions
- Reproducible defects: GitHub Issues
- Security vulnerabilities: Private Vulnerability Reporting

- 安装问题与展示：GitHub Discussions
- 可复现缺陷：GitHub Issues
- 安全漏洞：Private Vulnerability Reporting

Please include your Codex version, operating system, installation path, and a screenshot
or validation output when asking for help.

求助时请提供 Codex 版本、操作系统、安装路径，以及截图或验证输出。
