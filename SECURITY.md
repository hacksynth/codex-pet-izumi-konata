# Security Policy / 安全政策

## Supported versions / 支持版本

Only the latest GitHub Release and the current `main` branch receive security fixes.

仅最新 GitHub Release 与当前 `main` 分支接收安全修复。

## Reporting / 报告方式

Do not open a public issue for a vulnerability. Use GitHub Private Vulnerability
Reporting from the repository Security tab. Include affected files or workflow, impact,
reproduction steps, and a proposed mitigation when available.

请勿为漏洞创建公开 Issue。请通过仓库 Security 页面中的 GitHub Private Vulnerability Reporting
提交报告，并尽量提供受影响文件或工作流、影响、复现步骤和建议缓解方式。

The maintainer will acknowledge a report within 7 days and provide a status update within
14 days. Asset copyright questions are not security reports; use Discussions instead.

维护者将在 7 天内确认收到报告，并在 14 天内提供状态更新。素材版权问题不属于安全漏洞，请使用
Discussions。
